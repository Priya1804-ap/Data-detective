# 🕵️ Data Detective

Data Detective is an interactive data analytics and machine learning game.

## 🎯 Project Objective

The goal of this project is to create a game where players solve real-world business cases by analyzing data, writing SQL queries, creating visualizations, and using machine learning.

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- SQL
- Machine Learning
- Plotly
- Streamlit

## 🎮 Planned Features

- Business data investigation
- SQL challenges
- Data visualization
- Machine learning cases
- Hints and scoring
- Levels and difficulty
- Leaderboard
- Player performance dashboard

🟡 Currently in development.
